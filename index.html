Privacy Policy

Personal WHOOP API client · Last updated 7 October 2026

Who this applies to

This is a private, single-user application. It is used only by its owner to read the owner's own WHOOP data. It is not offered to, or used by, anyone else, and it does not collect data about any other person.

What data is accessed

When the owner approves access through WHOOP's sign-in screen, the application reads the owner's own WHOOP profile, body measurements, physiological cycles, recovery, sleep and workout records. It requests read-only access. It never writes to or changes anything in the WHOOP account.

How the data is used

The data is used only for the owner's personal analysis of their own health and training. It is not used for advertising, profiling, marketing or any commercial purpose.

Where the data is stored

Everything stays on the owner's own computer. Access credentials are held in the macOS Keychain, and downloaded records are saved as local files. The application has no server, no cloud database and no analytics or tracking, and it sends data to no one other than the WHOOP API itself.

Sharing

The data is not sold, rented, shared or disclosed to any third party.

Retention and deletion

Data is kept on the owner's computer until the owner deletes it. Access can be withdrawn at any time by removing the application from the WHOOP account settings, or by running the application's logout command with the revoke option. Deleting the local data folder removes all stored records.

Changes to this policy

If the way the application handles data changes, this page will be updated and the date above will change.
